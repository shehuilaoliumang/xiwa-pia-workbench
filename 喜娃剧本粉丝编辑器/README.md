# 喜娃剧本粉丝编辑器（桌面版）

给粉丝使用的独立剧本编辑器：**可新建剧本**（空白创建，或粘贴正文 / 上传 TXT / DOCX 自动解析成
台词段落），也可导入主播导出的单篇剧本 ZIP 进行编辑（台词、插图、音视频配本），再导出新 ZIP 还给主播，
主播在其工作台「内容管理 → 剧本资料 → 导入单篇剧本」中检查后，再选择新增、跳过或明确覆盖。

与主播工作台完全隔离：只编辑剧本，不碰主播后台；所有资料只保存在本机，不联网。

2026-09-30 已适配主播端的角色默认配色字段，粉丝源服务版本为 `0.2.1`。原先只保留、继承这个字段，缺少直接设置入口；本次补充「角色与默认颜色」面板。正文、颜色片段、来源、图片及音视频时间点的源码闭环验证已完成；新面板的界面验收结果另记。目录里的旧 EXE 尚未重新构建，不能当作已包含本轮更新的交付。具体状态见[粉丝编辑器适配与交付](../docs/粉丝编辑器适配与交付.md)。

本工具有独立的新建、正文和音视频配本编辑流程。主播工作台新增的本机自动草稿恢复、80步撤销/重做、已保存历史恢复和编辑排版预览没有移植到粉丝工具；这些操作仍在主播工作台进行。

## 文件结构

```

├── fan_entry.py           # exe 入口（释放桌面组件、启动 Electron 桌面窗口、安全退出）
├── import_parser.py       # 与主播端同步核验的 TXT/DOCX/粘贴文本解析
├── script_package.py      # 独立 v1 包校验/打包实现，保留粉丝工作区流程
├── storage.py             # 供粉丝工具使用的共享数据校验实现
├── templates/editor.html  # 编辑页面（含新建剧本弹窗）
├── static/editor.js       # 页面逻辑（新建 + 角色默认色 + 正文 + 音视频配本编辑）
├── static/editor.css      # 页面样式
├── desktop/
│   ├── main.cjs           # Electron 桌面窗口（单窗口 + 服务健康监控自动退出）
│   ├── package.json
│   └── runtime/           # 开发模式从主播端 desktop/runtime 复制的 Electron 运行时
├── build/
│   ├── create_flow_test.py        # 新建流程测试：解析→创建→编辑→导出→粉丝本地校验
│   ├── closed_loop_test.py        # 闭环测试：导入→编辑→导出→粉丝本地校验
│   ├── desktop_smoke_test.py      # 桌面冒烟测试：入口执行+窗口渲染+关停联动
│   ├── compatibility_backend_test.py # 当前角色默认色、来源及颜色片段专项
│   ├── desktop_release_test.py   # 桌面组件缓存升级专项（不构建EXE）
│   ├── 喜娃剧本粉丝编辑器.spec      # 打包配方（含 add-binary 的 Electron 运行时）
│   └── dist/喜娃剧本粉丝编辑器.exe   # 构建产物；大小和哈希须按新构建实测
└── fan-data/              # 默认工作区资料；exe 所在目录不可写时另有回退
```

## 使用方式（外行人）

1. 拿到已经构建并验证的新版后，双击 `喜娃剧本粉丝编辑器.exe`，首次启动自动释放桌面组件（通常约 1 分钟，以电脑为准），
   然后打开「喜娃剧本粉丝编辑器 · 桌面版」窗口（不用浏览器）。
2. 新建剧本：点右上角「＋ 新建剧本」——直接「创建空白剧本」，或粘贴正文 / 上传 TXT / DOCX
   后点「解析预览」，确认识别结果（剧名、作者、角色、段落数）后点「创建剧本并开始编辑」。
3. 编辑：剧名/作者/简介/配音备注/标签/显示状态；正文段落可改词、改角色名和颜色、增删段、排序；
   插图可上传、替换、删除；音视频配本可上传/解除关联本地音视频、播放器取真实时长、
   标记/编辑时间点（时间、名称、勾选关联段落）、保存全部时间点。
   重新打开剧本时会自动恢复已关联的音视频与时间点，无需解除再重传。
   需要指定某个角色的默认颜色时，在「基本信息」与「正文段落」之间打开「角色与默认颜色」，操作方法见下面说明。
4. 点「保存修改」→「导出剧本包（ZIP）」→ 把下载的 ZIP 发给主播。主播检查后，同名相同内容会跳过；同名但不同默认跳过，确认差异后才能覆盖选定的旧本；无同名可新增。
5. 用完点「安全退出」或直接关闭窗口，工具自动停止。

## 界面布局

- 编辑页顶部操作栏（剧名 + 保存修改 + 导出剧本包）固定置顶，滚动正文时始终可见。
- 宽屏下，右侧「音视频配本」面板固定；时间点列表较长时在面板内部滚动，
  「保存全部时间点」条吸附在面板底部。
- 宽屏下，中部「基本信息 + 角色与默认颜色 + 正文段落」独立滚动；窄屏改为上下排列，正文和配本按内容高度展开，在内容区滚动，避免互相遮挡。
- 宽屏欢迎页右侧显示配本说明；点顶部「剧本列表」按钮可随时隐藏/显示最左侧剧本列表。

## 设置角色默认颜色

「角色与默认颜色」位于「基本信息」与「正文段落」之间，可以新增角色和默认色、修改已有默认色，或清除指定角色的显式默认色。即使正文还没有这个角色的台词，也可以提前设置。选用角色时优先采用这里设定的颜色；清除显式默认色后，退回该角色正文中首次出现的颜色，没有可用颜色则保留本句当前色。

面板操作只影响以后选用角色时的颜色，不会批量改动已经录入的台词颜色或多色片段（runs）。设置后须点顶部「保存修改」才正式保留；保存的角色默认色会随「导出剧本包（ZIP）」一起带给主播。未保存就关闭，不应当作已经保留。这不是主播端的「统一已有台词颜色」功能。

## 开发者：构建与测试

以下命令在粉丝工具目录中执行。先核实维护用 Python 能导入应用依赖和 PyInstaller；项目的便携运行时并不等于已经安装了构建工具。完整 Electron 运行时应位于主项目 `desktop/runtime/`，不能只准备一个 `electron.exe`。当前配方按 `SPECPATH` 解析项目位置，支持不同检出目录。

```bat
rem 核实维护解释器中的构建工具；失败时先处理维护环境
python -m PyInstaller --version

rem 构建 exe（配方已包含模板、静态文件及完整 Electron 运行时）
python -m PyInstaller --clean --noconfirm ^
  --workpath build\work --distpath build\dist build\喜娃剧本粉丝编辑器.spec

rem 开发模式跑服务 + 桌面窗口（控制台可见日志）
python fan_entry.py --port 8766 --data-dir fan-data-dev

rem 闭环测试（脚本模式）
python build\closed_loop_test.py

rem 角色默认色、来源和颜色片段兼容专项（脚本模式）
python build\compatibility_backend_test.py

rem 桌面组件缓存升级专项（模拟冻结资源，不构建EXE）
python build\desktop_release_test.py

rem 闭环测试（针对 exe 本体）
set FAN_EXE=build\dist\喜娃剧本粉丝编辑器.exe
python build\closed_loop_test.py

rem 桌面冒烟测试（针对 exe 本体；建议把 exe 复制到临时目录再跑，避免在 build\dist 释放桌面组件）
set FAN_EXE=C:\path\to\copy\喜娃剧本粉丝编辑器.exe
python build\desktop_smoke_test.py
```

先运行源码检查，再将新 EXE 复制到新的测试目录，验证首次启动、保存、导出、关闭与重新打开。使用独立 `--data-dir`，不要指向粉丝正式工作区或主播的 `instance/`。当前旧产物不能替代新版 EXE 验收；构建后报告实际文件大小、SHA-256和测试结果。`fan-data/`、`fan-data-*/`、桌面运行时、构建临时目录及 `build/dist/` 不进入 Git。

真正与当前主播系统交换的验证入口在工程根目录：`tests/fan_exchange_compatibility.py`。先在根目录执行 `runtime\python.exe -X utf8 tests\fan_exchange_compatibility.py`；设置 `FAN_EXE` 为新构建文件的绝对路径后，再执行同一命令验证EXE。上面的两个旧流程使用粉丝自己的包校验模块，不能单独证明当前主播兼容性。界面与真实桌面脚本为根目录 `tests/browser_fan_editor.cjs`、`tests/desktop_fan_editor.cjs`，运行环境和交付步骤见[适配与交付](../docs/粉丝编辑器适配与交付.md)。

## 兼容性保障

- 新建剧本与导入/导出使用 `xiwa-script-package` v1。2026-09-30 已核对共享归一、资源、包验证和文本解析共12个函数与当前主播实现一致；两个工具的完整源码和导入流程仍各自独立，不可整文件直接覆盖同步。
- `role_colors` 支持角色名与 `#RRGGBB` 默认颜色，最多200名；导入、创建、保存和导出保留该字段，旧包缺少时按空设置兼容。普通保存未提供该字段时保留已有配色设置。
- 「角色与默认颜色」面板设置显式默认色，并在正式保存后写入上述字段。清除设置不删除正文角色或重写旧句；正文首色及本句当前色的回退规则见上面的操作说明。该面板的本次界面验收结果以适配记录为准。
- 文本解析（`import_parser`）：粘贴文本或 TXT/DOCX → 识别剧名/作者/「角色名：台词」段落，
  边界一致（30 万字符、10000 行、TXT 2 MB / DOCX 10 MB、安全 ZIP 校验）。
- 正文/配本采用相同的数据约束：音视频上传校验（容器签名 + 200 MB 上限）、
  时间点（at 唯一、须勾选存在的段落、≤5000 个）、删除被时间点引用的段落在保存时报错
  （"删除正文前请先调整相关时间点"，与主播端一致，不会自动剪枝）。
- 媒体文件以 SHA-256 命名存入工作区 files/，导出时重新哈希校验；图片经
  `decode_background`（12 MB 内 PNG/JPEG/WebP，剔除 EXIF，限静态图）。
- 打开剧本即自动创建播放器并加载已关联媒体（早期版本只在重新上传后创建播放器，
  导致重启工具后旧媒体看似无法加载，已修复）。
- 未修改文字的原多色片段和段落来源保留；改词会丢弃失效的颜色片段（runs），改本句颜色则把旧片段统一成新句色，避免主播端渲染错位。正常编辑保留已有段落标识与来源记录，不能伪造原始来源。
- 桌面窗口为 Electron 单窗口（1280×840，可缩放），页面安全退出时服务停止、窗口自动关闭；
  直接关窗口则入口检测到 Electron 退出后关停服务，不留后台进程。
- 服务健康检查返回当前绝对 `data_dir`，供桌面壳核对工作区身份并启用退出监控；后端专项及真实桌面安全退出联动均通过。

本轮验证包括9项粉丝后端专项、5组“当前主播 API → 粉丝 HTTP 服务 → 当前主播 API”源码闭环、7组Edge界面检查、5组实际Electron窗口检查、源码自启动/关停及3项桌面缓存升级专项。当前16篇在生产只读副本中逐篇核对文字、runs、来源、默认色、图片/媒体字节及时间点。不改内容导回时查重跳过，修改后明确覆盖则保留主播目标ID、队列、冻结展示并记录旧历史。正常、窄屏及125%窗口截图已目视检查。证据与限制见[适配与交付记录](../docs/粉丝编辑器适配与交付.md)。这些结果不表示旧 EXE 已更新；新构建产物仍须单独验收。

## 数据与安全

- 工作区默认保存在 exe 同级 `fan-data/workspaces/`。exe 所在目录不可写时，使用 `%LOCALAPPDATA%\喜娃剧本粉丝编辑器\fan-data\workspaces\`；启动日志会记录实际目录。删除工作区只删本地，不影响主播端任何资料。
- 仅监听 127.0.0.1，页面带 CSRF 校验 + CSP；主播端同款包格式校验拒绝坏包/超限包。
- 导出的 ZIP 由主播端执行查重：相同内容跳过，同名不同默认跳过并可明确覆盖，无同名时新增。粉丝工具本身不读取或修改主播后台。
- 完整桌面组件首次释放到可写运行目录的 `desktop/`；之后启动检查桌面入口和版本文件，有变化则更新。运行时缺少关键文件或版本变化时补齐，其余可复用；不删除粉丝工作区。

粉丝服务与 `desktop/package.json` 的桌面壳目前均为 `0.2.1`，分别记录；版本号不能代替新EXE本体的运行和交换验收。
