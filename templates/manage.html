AI 生成设置

生成服务需要联网与密钥。未配置密钥时，「模拟平台」可用于先跑通流程。密钥保存在本机，不会随剧本导出。

平台密钥（选填）

未配置密钥时可用「模拟平台」先跑通流程；配置真实密钥后即可调用豆包 Seedance / 通义万相生成。

字节 · 豆包（Seedance 视频 / Seedream 角色卡 · 同一 Key）

注意区分：API Key（AKLT…，用于实际生成，必填）；AccessKey / SecretKey（同为 AKLT… 开头，仅用于查询「已开通模型」以自动过滤下拉列表，可选）；豆包语音 API Key（配音专用，请到豆包语音控制台「API Key 管理」获取，与方舟 Key 不通用）。三个输入框留空保存都会保留已保存的值，不会被清空。

如何获取字节 Key（约 5 分钟）
  1. 打开火山方舟控制台 console.volcengine.com/ark，手机号注册并完成实名认证。
  2. 在「开通管理」中开通豆包大模型服务（Seedance 视频、Seedream 图像）。
  3. 进入「API Key 管理」→ 创建 API Key，复制 AKLT 开头的密钥，粘贴到上方「API Key」输入框。
  4. 点「测试连接」验证通过后，保存设置即可使用。
  5. （推荐）想自动「只显示已开通模型」：点击控制台右上角头像 → 「访问控制」→「API 访问密钥」→「创建密钥」，复制 AccessKey 与 SecretKey（均为 AKLT 开头）填入上方对应输入框 → 保存后点「测试开通状态」即可看到已开通的模型，未开通的将不再出现在下拉列表中。
阿里 · 通义万相（视频 / 角色卡 / 音乐 / 配音 · 同一 Key）

如何获取阿里 Key（约 5 分钟）
  1. 打开阿里云百炼 bailian.console.aliyun.com，注册并完成实名认证。
  2. 在百炼控制台开通「通义万相」「Fun-Music 音乐生成」「Qwen-Audio TTS 语音合成」等服务。
  3. 进入「API-KEY」管理 → 创建 API-KEY，复制 sk- 开头的密钥；进入「工作空间」复制业务空间 ID（音乐/配音生成需要）。
  4. 粘贴到上方输入框 → 点「测试连接」验证通过后，保存设置即可使用。

实测未开通的模型会自动隐藏（如字节 Seedream 全系未开通时下拉会提示无可用）。去平台控制台开通后，点「重置未开通记录」即可恢复全部模型再选择。
