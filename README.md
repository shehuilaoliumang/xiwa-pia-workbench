# 内容管理工作台

本地运行的通用内容管理工作台：在一个本地服务里完成**内容管理**、**展示控制**与**展示窗口**三件事——整理分组与条目、准备并按画幅排版、把内容输出到独立的观众窗口。

技术栈为 Python + Flask + Jinja + SQLite，默认只监听 `127.0.0.1:8765`，只允许本机访问，日常使用无需联网。桌面组件基于 Electron，与服务共用同一份内容数据。

## 功能清单

- **内容管理**：分组总览 → 组内条目列表 → 正文三级浏览；按名称、作者、角色或关键词搜索，按备注筛选，本场列表可排序；分组支持增删改、排序、隐藏与恢复，删除分组时先把条目转移到其他分组。
- **条目编辑**：正文文字与插图编辑、粘贴/TXT/DOCX 识别、逐段角色标签与条目配色；本机自动草稿、撤销/重做与已保存版本恢复；编辑时可选横竖屏排版预览，与预览同句双向定位。
- **分组主题与背景素材**：分组可设主题色与背板，排列支持自动或每行 1/2/3/4 组；背景素材可上传、命名、预览、替换与清除，内置或被引用的素材受保护。
- **单篇包交换（`content-package`）**：导出单篇 ZIP，携带正文、条目配色、插图与关联音视频时间点；导入先检查重复与同名差异，相同跳过，同名不同可跳过或明确覆盖，覆盖前保存旧版本。
- **展示控制**：从分组总览或指定条目准备内容，选择横竖屏、字号行距留白与正文方式（自动分页、连续滚动或音视频配本）；“逐步应用”核对后再上屏，也可显式选择“实时同步”。
- **展示窗口**：独立观众窗口由同一本地服务提供，可在支持窗口采集的直播软件中选择本窗口；刷新或重启后按已保存位置暂停恢复，无需 OBS 等中转软件。
- **本地音视频配本**：每个条目可关联一份本地音视频文件，手工标记时间点并绑定正文或插图；到点暂停、读完继续，台词组内可分页或滚动。
- **展示方案**：一套系统默认设置与最多 10 套自定义方案，每套同时保存横屏与竖屏排版。
- **备份与恢复**：完整 ZIP 备份、完整恢复，以及“仅合并条目”的逐篇新增/跳过/覆盖。
- **同步档位**：30／60／90／120 Hz 目标可选，默认 60，并显示实际发送与接收频率。
- **本地单机运行**：双击启动/停止、端口冲突处理、同资料目录单实例保护；资料保存在本机项目文件夹。

## 环境要求

- Windows 10 / 11（64 位）。
- 源码版：Python 3.10 或更新版本（含 pip）。
- 免安装交付包：自带便携 Python 与桌面组件，无需另装 Python、Node.js 或 OBS。
- 首次准备需要联网下载锁定的运行时、依赖与 Electron 桌面组件；完成后的日常使用不需要联网。

## 从 GitHub 下载后如何运行

仓库保存程序源码、初始示例资料与文档。`runtime/`、`vendor/`、`desktop/runtime/`、日常资料库 `instance/` 以及本地交付压缩包都不进入 Git。首次运行会依据初始资料建立一份新的本地资料库，不包含他人已有的修改、保存方案或音视频文件。

在完整下载或克隆的项目文件夹中打开终端，先装好 Python 3.10+（含 pip），然后运行：

```powershell
python tools/prepare_runtime.py
runtime\python.exe -X utf8 tools/prepare_desktop_runtime.py
```

首次准备需要联网，脚本会下载并校验项目锁定的便携 Python、依赖和 Electron 桌面组件。完成后双击 `启动工作台.cmd` 即可，以后的日常使用无需再执行准备命令。详细说明见[运行环境](docs/运行环境.md)。

**如果拿到的是 Windows 免安装交付包**：先右键 ZIP，选择“全部提取／解压到”，等待完整解压后，再进入同时包含 `启动工作台.cmd`、`run.py`、`runtime` 和 `desktop/runtime` 的普通文件夹启动。不要在 ZIP 窗口中直接双击启动文件；GitHub 的“Download ZIP”下载的是源码，不是免安装交付包。

**已有旧版本时**：先在旧版“内容管理 → 备份与恢复”导出完整备份，把新版解压到另一个文件夹；停止旧版后启动新版，再恢复该备份。保留旧文件夹，不要直接覆盖旧版 `instance/`。见[升级步骤](docs/使用说明.md#已有旧版本时怎样升级)。

## 启动与停止

1. 保留完整项目文件夹，双击 `启动工作台.cmd`。有桌面运行环境时优先打开桌面版，服务通常为 `http://127.0.0.1:8765/`；端口冲突时以启动窗口显示的地址为准。缺少桌面组件时，可双击 `浏览器模式.cmd` 使用浏览器版。
2. 在“内容管理”里按分组挑选条目、检查正文；需要展示时进入“展示控制”，从分组总览准备内容、横竖屏与排版，也可从阅读页直接送至展示控制预览。
3. 点“打开展示窗口”，在支持窗口采集的直播软件中选择本工作台的展示窗口。默认“逐步应用”，核对后点“应用到展示”；也可以明确选择“实时同步”。
4. 结束后在启动窗口按 `Ctrl+C`，或双击 `停止工作台.cmd`。只关闭网页或桌面窗口不会停止后台服务。

展示控制页进入或刷新时始终准备分组总览，不改动已上屏内容或播放状态。桌面模式在同一桌面应用内使用展示控制与展示窗口；浏览器模式须在同一浏览器、同一站点会话中使用，两种模式不要混用。详细路径、控件与恢复规则见[使用说明](docs/使用说明.md)。

## 目录结构

```
启动工作台.cmd / 停止工作台.cmd / 浏览器模式.cmd   双击入口
run.py                 本地服务入口（端口、单实例与启动提示）
app.py                 同源页面与 API（Flask）
storage.py             SQLite 资料、上屏快照、备份与恢复
import_parser.py       TXT/DOCX/粘贴正文的本地识别
script_package.py      单篇 content-package 的导入与导出
script_merge.py        完整备份的“仅合并条目”
template_config.py     读取 config/template.json 的命名与术语
config/template.json   应用名、简称、端口、术语、包格式与备份前缀
templates/ static/     页面模板与前端脚本、样式
data/seed.json         仅用于首次建库的初始资料
desktop/               Electron 桌面入口；desktop/runtime/ 不进 Git
docs/                  使用说明、方案文档与验收记录
tests/                 单元测试与浏览器验收脚本
tools/                 运行时准备、模板定制与打包脚本
evidence/              来源证据与归档原件
runtime/ vendor/ instance/   便携运行时、离线包、日常资料（均不进 Git）
内容编辑器/            子项目：内容编辑器
```

## 子项目「内容编辑器」

`内容编辑器/`（app_id `content-editor`）是独立交付的本地编辑工具：使用自己的 Python 本地服务与 Electron 桌面窗口，可由 PyInstaller 构建单独的 EXE。协作者可以新建条目、粘贴正文或读取 TXT/DOCX，也可以打开使用者导出的单篇 `content-package` ZIP，设置条目默认配色、编辑台词、插图及音视频时间点后交还使用者。

两端通过单篇 ZIP 交换，接收方按内容查重：完全相同跳过，同名不同默认跳过，可明确选择覆盖并保留旧版本。内容编辑器使用独立工作区（默认 `fan-data/`，不可写时回退到本机用户目录），不连接主工作台的资料库，也不包含主工作台的自动草稿恢复、撤销历史与排版预览。构建、测试与交付边界见[内容编辑器适配与交付](docs/内容编辑器适配与交付.md)及子项目 README。

## 常见问题

| 情况 | 处理方式 |
|---|---|
| 网址打不开 | 确认已完整解压并双击启动，启动窗口仍在运行；按该窗口显示的完整地址打开。程序停止后地址打不开属正常现象。 |
| 启动窗口闪一下就消失 | 若页面已打开且可用，可能是重复启动复用了原工作台；否则检查是否完整解压、`runtime/` 是否还在。出现错误文字时保留提示，不要删除 `instance/`。 |
| 没有打开桌面版 | 检查 `desktop/runtime/` 是否完整（不要只复制其中一个可执行文件）；可先用 `浏览器模式.cmd`，并查看 `instance/desktop.log` 的提示。 |
| 预览改了，展示没变 | “逐步应用”模式下需要点“应用到展示”；或改用“实时同步”。 |
| 视频／音频打不开或没有声音 | 预览默认静音，展示窗口可能需要点一次“播放”。程序不转码，编码不受支持时请换用可播放的文件或先使用纯正文。 |
| 换电脑或迁移资料 | 先停止工作台，再复制整个项目文件夹；大量编辑前到“内容管理 → 备份与恢复”下载一份完整备份。 |

## 维护与定制入口

- 命名、术语、端口与包格式集中在 `config/template.json`；换领域时优先改这一处，或用 `tools/customize.py` 按映射自动替换。步骤见[定制指南](docs/定制指南.md)。
- `tools/build_package.py` 生成交付包；运行时准备脚本为 `tools/prepare_runtime.py` 与 `tools/prepare_desktop_runtime.py`。
- `app.py` 定义同源页面与 API，`storage.py` 管理 SQLite 与状态规则，`templates/`、`static/` 提供页面；`data/seed.json` 仅用于首次建库，重建种子数据不会覆盖已编辑的数据库。日常资料位于 `instance/`，来源原件位于 `evidence/`。
- 子项目位于 `内容编辑器/`（`fan_app.py` / `fan_entry.py`，构建与测试见其 README）。
- Python 检查命令：`runtime\python.exe -X utf8 -m unittest discover -s tests -p "test_*.py" -v`。浏览器验收脚本位于 `tests/browser_*.cjs`，只对独立测试资料目录运行，不可对日常资料库执行。
- 当前验证结果与正式更新记录以[实施与验收记录](docs/实施与验收记录.md)为准。运行环境与个人资料不进入 Git，但保留在本地交付文件夹。
