## 从 GitHub 下载后如何运行

本仓库保存程序源码、初始剧本资料、原始 PPT 和使用文档。`runtime/`、`vendor/`、日常资料库 `instance/` 及本地交付压缩包不进入 Git。首次运行会依据初始资料建立新的本地资料库，不包含已有工作台的个人修改、保存方案或音视频文件。

**Windows 10/11（64 位）源码版：**先安装可用的 Python 3.10 或更新版本（含 pip），在完整下载或克隆的项目文件夹中打开终端，运行：

```powershell
python tools/prepare_runtime.py
runtime\python.exe -X utf8 tools/prepare_desktop_runtime.py
```

首次准备需要联网，脚本会下载并校验项目锁定的便携 Python、依赖和 Electron 桌面组件。完成后，双击 `启动工作台.cmd` 即可；以后的日常使用无需再执行准备命令。详细说明见[运行环境](docs/运行环境.md)。

**如果拿到的是 Windows 免安装交付包：**先右键 ZIP，选择“全部提取／解压到”，等待完整解压后，再进入同时包含 `启动工作台.cmd`、`run.py`、`runtime` 和 `desktop/runtime` 的普通文件夹启动。不要在 ZIP 窗口中直接双击启动文件。GitHub 的“Download ZIP”下载的是源码，不是免安装交付包。

**已有旧版本的用户：**先在旧版导出完整资料 ZIP，将新版解压到另一个文件夹；停止旧版后启动新版，再恢复备份。保留旧文件夹，不要直接覆盖旧版 `instance/`。见[升级步骤](docs/使用说明.md#已有旧版本时怎样升级)。

## 开始使用

1. 保留完整项目文件夹，双击 [启动工作台.cmd](启动工作台.cmd)。交付目录包含独立 Python 和依赖，默认打开桌面工作台，服务通常为 `http://127.0.0.1:8765/`；端口冲突时以启动窗口显示的地址为准。
2. 在“选本工作台”按分类查找、阅读剧本，按需“加入本场”并排序。内容准备不会改变观众画面。
3. 进入“播控台”，从分类总览准备展示内容、横竖屏及排版；也可从阅读页点“送至播控预览”直接准备该篇正文。
4. 点“打开独立展示窗口”，在抖音直播伴侣窗口采集中选择 **喜娃微PIA · 独立展示**（原 Edge／Chrome 采集目标需改选一次）。默认“逐步应用”，核对后点“应用到展示”；也可明确选择“实时同步”。正文默认自动分页后手动翻页，也可选择连续滚动；本轮媒体模式见[音视频配本](docs/音视频配本.md)。
5. 结束后按启动窗口的 `Ctrl+C`，或双击 [停止工作台.cmd](停止工作台.cmd)。

普通播控入口与刷新始终准备分类总览，不改已上屏内容或播放状态。桌面模式在同一桌面应用内使用播控与展示；浏览器模式按同一浏览器、同一站点会话中的一个播控页和一个观众窗口使用，勿跨模式混用；窗口入口会复用已有展示窗口。详细路径、控件及恢复规则见 [使用说明](docs/使用说明.md)。

## 现行功能

- **选本与资料管理**：分类总览 → 分类内剧本 → 正文；搜索、配音备注筛选、本场列表排序；分类与剧本维护、隐藏和恢复，含本分类删除时先转移。
- **单篇剧本交换**：导出单篇 ZIP，携带正文、角色配色、图片和关联音视频时间点；核对后导入到所选分类，新增副本而不覆盖旧本。正文导入附可复制的 AI 整理提示词。见[使用说明](docs/使用说明.md#单篇剧本导入与导出)。
- **正文图片**：手动上传 PNG、JPEG、WebP，在任意段后插入；支持大图预览、替换、移除及文字/图片上下排序。保存剧本后生效，图片随备份恢复；[操作步骤](docs/使用说明.md#手动添加正文图片)。
- **正文导入与角色复用**：粘贴文本或读取 TXT/DOCX，按本地规则识别后核对原文，再填入草稿并保存；默认追加，明确替换文字时保留原插图；同本角色候选可复用，也可自由输入。
- **分类主题与背景素材**：自动或每行1/2/3/4类、独立背景浓度；单列悬停放大并展示摘要。背景可上传、预览、改名、选用和清除，内置及被引用素材受保护。
- **横竖展示与走本**：独立观众画布、连续滚动、暂停、速度和定位；按画幅、字号、行距及留白自动分页，人工上一页/下一页。原文、角色颜色和插图保留。
- **清晰预览与快捷键**：竖屏预览加大，可放大至独立工作区，保持当前页和媒体位置；点击预览后用方向键翻页、选段或切台词组，目录用方向键选卡片、Enter进入。
- **预览与即时播控**：画面内或外置操作栏；逐步应用和实时同步可选。同一桌面应用内连续同步位置、翻页及分类/剧本/正文悬停反馈；浏览器模式须同浏览器同站点。未应用草稿与即时播控分开。
- **音视频配本**：每篇关联本地音频/视频，手工时间点多选文字或插图，到点暂停、读完继续；每组默认分页，翻页不影响媒体进度；自动或手动台词，竖屏上下、横屏左右可换。无需生成或转码，纯正文仍可独立使用。
- **展示方案**：系统默认设置及最多10套自定义方案，每套包含横竖排版。保存方案不改变当前展示或当前保存排版，载入遵循所选反馈方式。
- **资料与恢复**：本地数据库、修改记录、完整ZIP备份与恢复；原始PPT证据独立保留。展示窗口刷新或服务重启后暂停恢复，播控页刷新不主动发布草稿。
- **同步档位**：30／60／90／120 Hz 目标可选，默认60，并显示实际发送和接收频率；这是工作台消息频率，不等于直播伴侣采集帧率。
- **独立运行**：免安装交付包自带便携运行时，源码版可通过准备脚本安装；支持双击启动/停止、端口冲突处理和同资料目录单实例保护。

初始资料来自两份已归档PPT：14篇剧本/选段、6个初始分类、69页正文及7张正文插图，保留角色、提示和来源映射。这些是初始收录事实，后续数量以用户维护的资料库为准。

用户使用抖音直播伴侣窗口采集，现行桌面模式请选择“喜娃微PIA · 独立展示”。用户已初步反馈最小化同步似乎恢复；换电脑、调整采集方式或媒体后，应先在伴侣预览中确认画面和声音。播控台窗口状态并不检测伴侣实际采集结果，工作台不直接推流。详见[窗口采集说明](docs/使用说明.md#抖音直播伴侣窗口采集)。本地音视频配本已完成；AI 生成、转码/剪辑、语音识别、自动字幕对齐、多人控制、跨设备实时同步、公网访问及 Sites 发布仍不在范围内。

## 维护入口

`app.py` 定义同源网页/API，`storage.py` 管理 SQLite 与状态规则，`templates/` 和 `static/` 提供页面。`data/seed.json` 仅用于首次建库；重建种子数据不会覆盖已编辑数据库。个人工作资料位于 `instance/`，原件位于 `evidence/`。

Python检查命令：`runtime\python.exe -X utf8 -m unittest discover -s tests -p "test_*.py" -v`。浏览器验收脚本位于 `tests/browser_*.cjs`，只对独立测试资料目录运行，不可对日常资料库执行。当前验证结果和正式更新记录以[实施与验收记录](docs/实施与验收记录.md)为准。运行环境与个人资料不进入 Git，但保留在本地交付文件夹。
