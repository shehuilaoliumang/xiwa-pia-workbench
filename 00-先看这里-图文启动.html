内容管理工作台 · 零基础启动说明

先解压，再双击。
3 步打开你的工作台。

程序已自带运行环境。不用安装 Python、Node.js 或 OBS，日常使用不用联网。适用 Windows 10 / 11 的 64 位电脑，完整交付包已附带桌面展示组件。

1先把压缩包解压出来

  1. 找到收到的 ZIP 压缩包，右键 → 全部提取 / 全部解压缩。
  2. 解压到桌面、“文档”或 D 盘的普通文件夹，等待完成。
  3. 打开解压后的文件夹，直到看到 启动工作台.cmd，同一层还有 desktop、runtime、instance、docs 等文件夹。

不要在压缩包里面直接启动。保留整个文件夹，不要只把启动文件拖到桌面。以后继续用这次解压出的文件夹，不要反复解压旧包覆盖新资料。

有些电脑会隐藏“.cmd”，只显示“启动工作台”，这是正常的。

2双击“启动工作台”

在刚才的文件夹里双击 启动工作台.cmd。

会出现一个黑色文字窗口，然后桌面工作台会自动打开；缺少桌面组件时使用浏览器版。黑色窗口请一直保留，可以最小化。

需要浏览器版界面时，双击“浏览器模式.cmd”。展示控制与展示窗口请在同一桌面应用中操作，或都在同一浏览器中操作，不要混用。桌面版从顶部“内容管理”进入分组目录。

浏览器没有自动打开时，在浏览器最上方的地址栏输入：

http://127.0.0.1:8765/

如果黑色窗口显示了不同的网址，使用它显示的完整地址。网址只在运行工作台的这台电脑上使用，不要输进网页搜索框。

3内容管理 → 预览 → 应用

  1. 可直接在展示控制里准备内容，也可点顶部“内容管理”，按分组挑选条目、检查正文。
  2. 点 “送至展示控制预览”。
  3. 把“操作反馈”选为 “逐步应用”，先检查内容、横竖屏和字号。
  4. 点 “打开展示窗口”。这是给观众看的窗口。
  5. 回展示控制页点 “应用到展示”，观众窗口才更新。

编号对应关系：阅读页里 ② 是“送至展示控制预览”；预览里 ② 选“逐步应用”，③ 把内容应用给观众。新版预览另有同步档位选项。

桌面版在支持窗口采集的直播软件中，选择本工作台的展示窗口。换电脑后，开播前先在直播软件的预览里试一次翻页、滚动和最小化；如果停帧，恢复展示窗口并核对采集目标。

初次使用先保留“逐步应用”。切到“实时同步”时，当前已就绪预览就会同步出去，后面的操作也会同步。工作台负责准备和输出展示内容，不会自动替你开启直播。

用完怎样关闭？

回到文件夹，双击 停止工作台.cmd。看到停止完成后，按提示按任意键关闭黑色窗口；桌面窗口会在数秒内自动退出。浏览器模式的网页可手动关闭。

也可以在最初的黑色窗口里按 Ctrl+C。只关闭浏览器网页或桌面窗口，不会停止后台服务。

同步档位先用默认 60

交互预览提供 30、60、90、120 Hz。旁边显示实际发送／接收次数；这些数字不是直播帧率。较高档位受电脑和显示器影响，音视频时间校准另有独立节奏。

遇到这些情况，按这里检查

网址打不开

确认已完整解压并双击启动，黑色窗口仍在运行。使用黑色窗口里显示的完整地址。程序停止后网址打不开是正常现象，下次重新启动即可。

黑色窗口闪一下就消失

如果网页已经打开且能用，可能是重复启动，程序复用了原来的工作台。如果网页也打不开，检查是否在压缩包里直接启动、runtime 文件夹是否完整。出现错误文字时，拍下完整提示交给提供程序的人，保留现有资料。

预览改了，观众还没看到

逐步应用模式下，需要点击“应用到展示”。这让你能先检查，再把内容发给观众。

视频打不开或没有声音

确认保留完整项目文件夹。浏览器若提示尚未允许播放，在观众窗口点击播放，必要时点击“开声音”。预览默认静音；实时同步时声音由展示窗口播放。媒体仍无法打开时先用纯正文，保留错误提示交给提供程序的人。

已经有旧版资料 怎样换新版

先在旧版“内容管理 → 备份与恢复”导出完整备份。新版解压到另一个文件夹，先停止旧版，再启动新版并恢复备份。不要直接覆盖旧版的 instance 文件夹。新包带的是打包时资料快照，不会自动带上你后来在旧版的编辑。

换电脑或想保留一份资料

大量修改前，到“内容管理 → 备份与恢复”下载完整备份。换电脑或移动项目文件夹前先停止工作台，再复制整个文件夹。不要用旧压缩包覆盖正在使用的资料。
