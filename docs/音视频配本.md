更新日期：2026-09-18；对应[项目计划书 v0.6](项目计划书.md)。

**当前状态：本地音视频配本及台词组内分页已正式更新。每组台词默认分页，也可选择连续滚动阅读。《爱情公寓》样片已关联，初次导入未预填时间点，后续以当前资料为准。** 最新验证、正式更新和页面核验见[实施与验收记录](实施与验收记录.md)。

## 能做什么

一篇剧本可选关联一份本地音频或视频。你播放到需要停下来的地方，标记时间，再勾选对应的一段或多段文字/插图。展示时媒体到点暂停，台词显示在独立区域，读完点“读完继续”。没有媒体的剧本仍能正常选本、阅读、滚动和分页。

这个功能不生成视频，不转码、剪辑或混音，不做语音识别（ASR），不自动推断时间点，也不把字幕烧进视频。已有 PPT 的音乐/表演提示不是已配好的音轨或可靠时间码。

## 1. 为剧本关联文件

入口有三处：阅读页的音视频按钮、内容管理中的剧本音视频入口、播控“准备展示内容”中所选剧本下方的“管理音视频与暂停点”。新建剧本请先保存，再配媒体。

在配本页“1 · 关联音视频”选择文件，点击“上传并关联”。支持 MP4、WebM、MP3、WAV、M4A、OGG，单文件最多 **200 MB**。文件复制到工作台本地素材目录，页面不依赖桌面原路径继续播放。

上传会核对实际容器签名、大小并计算 SHA-256，不采用表单提供的任意路径或媒体信息；不做完整编码检测。扩展名允许不代表所有编码都能被当前浏览器播放。若加载或解码失败，请换用浏览器支持的文件，或切回纯正文；程序不会自动下载或转码。

- **替换文件**：确认后保存新关联，清空当前媒体的时间点及旧时长；新文件可重新配点。即使上传相同文件，也按替换处理并清空时间点。
- **解除关联**：清除当前篇目的媒体和时间点，保留正文。旧文件仍可能被历史或已上屏画面使用，不直接物理删除。
- 上传、替换、解除关联会即时写入资料库；它们与下面需要单独保存的时间点草稿不同。管理操作不直接更换观众已经看到的快照。

## 2. 标记时间并选择台词

1. 用播放器播放或拖动进度，到需要停下的位置点“暂停并标记当前时间”。
2. 在“2 · 时间点”选择已有点，可试听、修改或删除。
3. 在“3 · 为时间点选择台词”填写分:秒或秒数，如 `01:23.500` 或 `83.5`；可补充时间点名称。
4. 勾选对应文字或图片段落。可以多选，右侧/下方“所选内容预览”供核对；图片按原图展示，不在此处 OCR 或重写其中的文字。
5. 点击“保存全部时间点”。勾选和改时间先留在页面，只有保存成功才入库；“放弃未保存修改”恢复已保存内容。

每个时间点至少选一块。时间必须是有限、非负秒数，不能超过已经保存的时长；时间点按秒数排序。相同秒数只能有一个点，需要多段时在该点多选。可以删除全部时间点并保存空列表，媒体仍可播放和人工定位。

时间点通过稳定正文 ID 关联，修改该块文字可保留关联；删除被关联的块或用导入替换相关正文前，要先调整时间点。来源字段和原始 PPT 不受配本修改影响。

## 3. 预览、上屏与台词模式

保存后点“去播控预览”，或在播控选定剧本。在“正文阅读方式”选择第三项“音视频配本 · 时间点暂停”；未关联有效文件时此项不可用，目录展示也不因媒体设置改变结构。

| 设置或操作 | 行为 |
|---|---|
| 随暂停点自动显示 | 媒体到手工时间点暂停，并显示该点所选文字/图片组 |
| 手动选择台词 | 用“上一组 / 下一组”选组；媒体仍在手工时间点暂停，字幕不随暂停点强制切换 |
| 没有时间点 | 不自动制造暂停点；正文仍可显示并用台词按钮定位 |
| 读完继续 | 从当前暂停点继续；不会再次卡在同一个已经处理的点 |
| 拖动媒体进度 | 跳到指定位置并暂停，再决定何时播放；回到起点可重新走本 |
| 竖屏 | 上方媒体、下方台词；音频使用音频画面区域 |
| 横屏 | 左右分区，可选“视频在左 · 台词在右”或相反 |
| 切换画幅 | 当前媒体模式保持为媒体；台词方式、左右位置及其他排版取对应方向设置 |

媒体台词模式、组内阅读方式和横屏位置可随现有展示方案保存。每组台词默认自动分页，用“上一页/下一页”阅读；也可在“组内台词阅读”选择连续滚动。正式使用前应核对字号与可读性，不会自动删减原文。

**逐步应用**：操作只留在预览；点“应用到展示”时，内容、媒体、当前台词组及组内页码、媒体位置一起应用，并暂停。

**实时同步**：明确启用并绑定当前预览后，媒体播放、暂停、拖动、台词换组与组内翻页随操作同步。切回逐步应用停止后续自动同步；陈旧预览或错误需要重新核对，不能自动发布尚未看过的资料。管理页保存和普通播控刷新不自动发布媒体。

## 4. 声音与即时控制

预览默认静音，可在逐步应用时点“试听声音”。实时绑定时预览静音被锁定，声音由观众窗口播放，避免同一段声音重复播放。

浏览器可能不允许无交互的有声自动播放。若观众窗口提示“浏览器尚未允许播放，请点按‘播放’”，在该窗口点击播放；需要时点“开声音”。这不能代替系统音量、输出设备或直播客户端声音采集设置，后者仍待真实客户端联调。

即时播控已移到预览底部：“暂停展示”常显，其他操作收进“展示控制”折叠区。它只控制已上屏内容，不覆盖未应用的预览草稿。媒体画面内另有播放/读完继续、进度、“上一组/下一组”，以及分页模式的“上一页/下一页”控件。

宽度大于 1040px 时左侧准备与设置合计跟随预览高度，设置中部独立滚动；小于或等于 1040px 按准备→预览→设置排列，设置自然展开。

## 5. 保存、刷新和备份

媒体位置保存秒数、当前台词组、组内页码和最近时间点；有时间点时一组对应该点关联的内容，没有时间点时一组对应一段正文或插图。应用和实时同步均携带当前组及组内页码；展示窗口刷新、程序重启和恢复备份后，恢复最近保存位置并保持暂停。意外断开不承诺逐帧精度。

资料 ZIP 包含媒体关联、手工时间点、当前媒体状态及仍被正文历史/上屏快照引用的媒体文件。单个媒体最多 200 MB，备份解压总量最多 **512 MB**，旧媒体历史也占容量。替换或解除关联不会自动删历史文件，因此多次配本后备份可能变大。

恢复校验成员路径、资源大小、SHA-256、容器签名与数据关联，先保存恢复前备份，再替换资料。失败不应留下半截哈希资源或部分更新数据库。两个原始 PPT 和程序运行时独立保存，不在资料 ZIP 中；迁移仍应停止服务后复制完整项目。

## 7. 维护接口与验收入口

| 入口 | 职责 |
|---|---|
| `GET /script/<id>/media` | 配本页面，同源 Flask/Jinja 提供 |
| `POST /api/scripts/<id>/media` | multipart `file` 上传，返回更新后剧本 |
| `DELETE /api/scripts/<id>/media` | 解除当前关联，返回剧本；不删历史引用文件 |
| `PUT /api/scripts/<id>/media/cues` | 保存 `{cues,duration?}`；返回更新后剧本 |
| `POST /api/preview` / `/api/apply` | 候选与冻结快照含媒体；`preview_media_state` 需要有效 `preview_token` |
| `POST /api/command` | `action:'media'`，校验 `snapshot_id`、媒体状态及可选 `revision`，播放标记必须为布尔 |
| `POST /api/checkpoint` | 可保存媒体状态；必须匹配当前 revision，不把检查点当新命令 |

`media` 保存路径、类型、名称、大小、SHA-256、可选时长和时间点；`media_state` 与 `state.playing` 分开。当前格式不包含自动生成结果、音轨转写或视频编辑工程。

首次媒体交付时的历史验证为 [test_media.py](../tests/test_media.py) 19 项及全套 83 项，覆盖大于旧图片 40 MB 限额的真实 WAV 备份恢复、伪造文件、非法时间点、上传/数据库失败、快照/历史保护、状态版本与旧数据兼容。浏览器验收 [媒体编辑器](../tests/browser_media_editor.cjs)、[媒体播放器](../tests/browser_media_player.cjs)、[媒体同步](../tests/browser_media_sync.cjs) 均通过，包含真实 MP4、WAV/WebM、0 秒时间点与回退重触发、确认/实时、手动台词、声音锁定、横竖交换、后台无观众不回跳及即时暂停不回旧检查点。当时相关列布局、设置、目录、反馈和分页回归通过；后续新增功能的最新验证与正式页面核验见[实施与验收记录](实施与验收记录.md)。


## 台词组内分页与同步

每个时间点关联的一组文字/插图默认自动分页，长台词按实际区域拆页并保留原文、角色和配色，插图适配单页。左右键或“上一页/下一页”翻本组台词，上下键或“上一组/下一组”切换组；切换组后从第一页阅读，组内翻页不改变音视频进度、播放状态或暂停点。

在播控台“组内台词阅读”可切换回连续滚动；该选项随横竖屏设置和自定义方案保存。无时间点时每个正文块作为一组，不把全部正文默认铺成滚动长页。确认模式应用当前组与页，实时模式同步组内翻页，重启/刷新按保存的组与页暂停恢复。分页窗口缩放只缩放画布，同画幅与排版的预览/观众页内容保持一致。
