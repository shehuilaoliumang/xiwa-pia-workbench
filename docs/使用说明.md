# 喜娃微 PIA 工作台使用说明

面向第一次使用者的带编号截图版本：[图文使用说明书（Word）](喜娃微PIA工作台_图文使用说明书.docx)。

本文按当前页面控件说明日常操作。最近的测试、备份与正式更新情况见[实施与验收记录](实施与验收记录.md)；程序更新后，已打开的操作页需刷新一次加载新版。

音视频配本与播控布局已完成验证并更新到日常工作台。《爱情公寓》样片已经关联，初次导入未预填时间点，后续以当前资料为准，可按下文查看或调整；验证结果、更新证据及正式页面核验见实施记录。

## 启动与关闭

1. 保留完整项目文件夹，双击根目录的[启动工作台.cmd](../启动工作台.cmd)。
2. 默认打开“喜娃微PIA工作台 · 桌面版”。免安装交付包已自带运行环境，无需安装 Python、Node.js 或 OBS。本地服务通常地址为 `http://127.0.0.1:8765/`。端口被其他程序占用时自动改用随后可用端口，以启动窗口显示的地址为准。
3. 使用期间保留启动窗口。结束后在该窗口按 `Ctrl+C`，或双击[停止工作台.cmd](../停止工作台.cmd)。

需要旧版浏览器入口时，可双击[浏览器模式.cmd](../浏览器模式.cmd)。缺少桌面组件时会回退浏览器模式，完整交付包应保留 `desktop/runtime/` 文件夹。只关闭桌面窗口不会停止后台服务；结束使用请运行停止入口。

重复双击启动会打开已有工作台，不应新建第二份资料或打断正在展示的内容。页面只允许本机访问；日常使用无需联网，也无需打开 Codex。

## 已有旧版本时怎样升级

1. 先在旧版“内容管理 → 备份与恢复”下载完整资料 ZIP，确认文件已保存。
2. 把新版完整解压到另一个普通文件夹，保留旧文件夹，不要直接覆盖旧版 `instance/`。
3. 双击旧版“停止工作台.cmd”，等旧版退出后，再启动新版。
4. 在新版“内容管理 → 备份与恢复”选择刚保存的资料 ZIP 并恢复；核对剧本、图片、背景和音视频时间点。
5. 桌面与浏览器各自保存的操作反馈、同步目标等偏好不在资料备份里，可按习惯重新设置。直播伴侣中改选“喜娃微PIA · 独立展示”，开播前试一次翻页、最小化恢复和声音。

## 选本与阅读

- “选本工作台”先展示分类总览：背景图、分类名称、剧本数量和最多三篇示例标题。点击分类进入二级目录，查看该类全部可见剧本的简介、作者、配音备注与标签；正文返回时回到所属分类，二级目录可返回分类总览。
- 按剧名、作者、角色或关键词搜索，也可按原配音备注筛选。总览中的搜索检索全部可见剧本，进入分类后搜索当前分类。
- 点击剧本进入正文，调整阅读字号和行距。资料页不再显示 PPT 页码或页码导航，直接按正文阅读；原始来源仍在内部保留。
- “原备注与待核事项”保留原稿疑点。原始 PPT 不会被网页编辑覆盖。
- 点击“加入本场”，在待展示列表中用上下箭头排序或移除。这一步只是准备内容，不会改动观众画面。

初始收录有 14 篇剧本或选段，初始“动漫影视本”为空；当前数量和分类内容以用户维护后的资料库为准。《爱情公寓》的原图中包含文字，已保留原图；没有目录简介的剧本不会自动生成简介。

## 预览与上屏

1. 从首页点“进入播控台”，或从顶部导航进入“播控台”。普通入口和刷新都直接显示分类总览，不沿用上次展示的位置；阅读页的“送至播控预览”则直接准备该篇正文。两种入口都只准备草稿，不改变当前展示。
2. 在“准备展示内容 → 目录范围”选择“按分类选择”或“本场待展示列表”。前者展示勾选分类的可见剧本，未勾选任何分类表示全部可见分类；后者仅展示已加入本场的剧本，空列表保持空，不回退为全库。
3. 点击预览中的分类，再点剧本进入正文。预览工具栏的返回按钮逐层返回；“准备展示内容”里的“剧本目录”按钮直接回到最外层分类总览，并保留当前分类或本场范围。分类勾选区可点击“全选分类”，一键选中全部可见分类并回到分类总览；旁边显示已选数量。已经全部勾选且位于总览时再次点击不会重复上屏。在“调整展示画面”选择横竖屏和排版。
4. 在“操作栏位置”选择“画面内 · 移入显示”或“画面外 · 始终显示”；外置工具位于预览下方，窄屏自动换行。可选段、前后切段、回顶部、试滚、翻页及调整字号，具体按钮随正文模式切换。
5. 在“操作反馈”选择“逐步应用”或“实时同步”。首次使用默认画面内操作栏和逐步应用；两项偏好保存在当前应用会话，桌面和普通浏览器分别保存。
6. 点“打开独立展示窗口”。桌面模式请在同一个桌面应用内使用播控与展示；浏览器模式须同一浏览器、同一地址和端口。入口会复用已有观众窗口；不要混用桌面播控和普通浏览器展示，也不要反向混用。跨设备实时同步不在当前范围内。

**逐步应用（确认后生效）**：预览只用于准备，点击“应用到展示”才更新观众窗口。选定的位置随内容和画幅一起上屏，并保持暂停；分页正文携带当前预览页，试滚也仅发生在预览中。

**实时同步**：选择此模式后，当前就绪预览的位置与播放状态立即同步；即使已在试滚，也从当前段落接续。之后选本、返回目录、选段、手动滚动后的段落位置、分页翻页、字号和画幅等改动自动同步；操作栏的开始/暂停也同步到观众展示，无需每步确认。手动定位或切换内容会停下滚动，便于从新位置开始。同一桌面应用内（浏览器模式为同一浏览器同一站点）的播控预览与独立展示窗口会连续同步画面位置，并即时跟随播放、暂停和速度；不再只靠段落跳转模拟同步。滚动模式按段落保存恢复位置，分页模式保存当前页。

播控页进入后台后，观众画面可继续按当前播放状态滚动；重新回来时优先读取观众窗口当前的位置，避免把画面拉回预览的旧位置。

切回“逐步应用”会停止发送后续自动同步，保留已应用结果。普通播控页刷新后回到分类总览，即使记住了实时模式，也不会自动发布初始草稿或暂停展示；再次进行预览操作后才继续实时同步。

若另一页面在预览后修改了资料，旧预览会被拒绝，自动同步停止。重新核对预览后，使用应用/同步按钮继续，避免未经查看的新内容直接进入展示。断开连接时同样会显示错误，不无限自动重试。

在“调整展示画面”中，“分类排列”可选自动或每行1/2/3/4类；自动最多为竖屏两类、横屏三类，分类较少时相应减少。单列采用左侧分类条、右侧摘要的方式：移入分类或用键盘聚焦时显示最多三篇剧本的标题、简介及已有要素，点击分类仍进入完整二级目录。单列分类悬停时轻微放大至 1.04 倍，背景加深。摘要和悬停反馈会跟随实时展示，确认模式只在预览中查看；实时模式也同步剧本卡片及正文的悬停焦点。

“分类背景浓度”单独控制分类卡片图片，0%为隐藏图片，100%为最清晰；“整页背景浓度”调整整体背景，两项互不代替。新分类背景默认80%，减少原来多层白色遮罩造成的过淡效果。列数和背景浓度也分别保存在横屏/竖屏配置中，点击“保存当前画幅设置”后下次进入继续使用，最新保存值优先于旧展示快照中的排版。

横竖屏的排版配置分别保存。目录与正文切换保留约 270 毫秒的短转场，选本页与正文往返也有转场，并遵循系统减少动态效果设置。

视口宽度大于 1040px 时，左侧“准备展示内容”和“调整展示画面”的合计高度跟随右侧预览面板，设置区中间控件可独立滚动，标题、方向与保存入口保留。宽度小于或等于 1040px 时按“准备 → 预览 → 设置”顺序堆叠，设置自然展开，避免嵌套滚动。

## 抖音直播伴侣窗口采集

### 默认桌面模式

1. 双击“启动工作台.cmd”，在桌面工作台进入播控台，点击“打开独立展示窗口”。
2. 在抖音直播伴侣的窗口采集中，选择 **喜娃微PIA · 独立展示**。原先选择 Edge／Chrome 的用户需要改选一次；主播仍在播控台操作。
3. 开播前在伴侣预览中试一次翻页或滚动。2026-09-18，用户初步反馈最小化后的同步“似乎已经解决”；可按当前已试用方式使用。换电脑或采集设置后，重新检查最小化及恢复时的画面；有音视频时也核对暂停点和声音。
4. 想重新看到展示窗口时，点“恢复展示窗口”或 Windows 任务栏中的展示窗口。该操作复用原窗口，不主动刷新、不暂停或重置内容。
5. 如实际采集再次停帧，先恢复展示窗口，确认伴侣仍选中上述窗口；必要时并排保持可见。记录发生时的状态和操作，以便继续排查。

播控台的窗口状态仅表示应用是否收到回应，**不能检测直播伴侣最终采集到的画面和声音**。用户本次反馈属于当前环境的初步试用结果，未等于所有设备、采集方式或媒体已逐项验收。只保留一个观众窗口，避免选错。

### 可选浏览器模式

双击“浏览器模式.cmd”时，播控和展示须在同一个 Edge／Chrome、同一地址和端口下使用，并在直播伴侣中选择相应浏览器展示窗口。这种模式仍受浏览器后台节流和停止绘制影响，建议保持展示窗口未最小化；遮挡也停帧时并排放置或使用第二屏。桌面模式的试用结果不能直接用于浏览器模式。

“未收到回应”可能是窗口关闭、两页不在同一应用会话，或浏览器限制了后台运行。先恢复窗口并核对模式和地址。加载程序更新前先结束使用，再重新启动；展示页重新加载会按既有规则暂停恢复。

后台布局等待、恢复同步和低频滚动兜底仍然保留，但它们不能保证普通浏览器最小化时持续绘制。技术参考：[MDN 页面可见性与后台限制](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)、[Chrome 后台动画帧与定时器说明](https://developer.chrome.com/blog/background_tabs)。桌面操作和验收记录见[独立展示器](独立展示器.md)。

## 放大预览与方向键

竖屏预览现在按可用宽度放大，桌面常规画面约宽460px。点击预览右上方“放大预览”，工作台会收起准备和设置区，竖屏画面最大约宽640px；横屏使用当前可用宽度。窄屏自动收窄，较矮的屏幕可上下滚动查看。点击“恢复工作台”或按 Esc 返回。放大、退出和调整窗口尺寸只改变本地预览大小，不改变观众画幅、字号、当前分页或媒体位置，也不触发应用。

先点击预览画面或预览空白区域，让键盘焦点进入预览，再使用以下快捷键：

| 当前画面 | ← / ↑ | → / ↓ | 其他 |
|---|---|---|---|
| 分页正文 | 上一页 | 下一页 | 到第一页/最后一页时停止 |
| 连续滚动正文 | 上一段 | 下一段 | 按段定位并暂停试滚 |
| 音视频配本（默认分页） | ← 上一页；↑ 上一组 | → 下一页；↓ 下一组 | 翻组内页不改变媒体进度和播放状态 |
| 音视频配本（滚动阅读） | 上一组台词 | 下一组台词 | 不用方向键拖动媒体时间 |
| 分类或剧本目录 | 左右按顺序、上下按当前网格行移动焦点 | 同左 | Enter 打开当前分类或剧本 |

方向键与点击对应按钮遵循相同反馈方式：逐步应用时只操作预览；实时同步时更新展示。按住不放不会连续跳多页。输入文字、选择下拉项、调节滑块或输入法组字时，方向键保留控件原有作用；不拦截带 Ctrl/Alt/Shift/Meta 的组合键。快捷键只在播控预览区域有效。

## 正文滚动、分页与媒体

正文默认使用“自动分页 · 手动翻页”，也可以在“调整展示画面 → 正文阅读方式”切换为“连续滚动”；已关联有效音视频的剧本还可选择“音视频配本 · 时间点暂停”。分页会按当前画幅、字号、行距和留白重新计算，较长的段落可以分到多页；显示内容仍使用原文及角色配色。翻页使用“上一页 / 下一页”和当前页提示，由人控制节奏，不自动滚动。

预览中的翻页遵循操作反馈：逐步应用模式只改变预览，应用时携带当前页；实时模式同步到展示。当前展示处于分页模式时，即时播控区也提供翻页按钮；先打开独立展示窗口，待页数就绪后即可操作。改变方向或文字设置后，先检查重新计算的页数和内容位置。

## 音视频配本与走本

1. 在剧本阅读页或内容管理列表点音视频入口；播控准备区选定剧本后，也可点“管理音视频与暂停点”。先上传本地 MP4、WebM、MP3、WAV、M4A 或 OGG，文件不超过 200 MB。
2. 在配本页播放/拖进度，点“暂停并标记当前时间”；也可手填分:秒或秒数。为这个时间点勾选至少一段文字或插图，可多选，右侧预览所选内容。同一时间需要多段时，在同一个时间点勾选，不创建重复秒数。
3. 点“保存全部时间点”才保存时间点草稿。可以删除全部时间点后保存空列表；替换媒体会清空旧时间点和时长，解除关联不会删除历史仍引用的文件。上传/替换/解除关联会即时保存，请区别于时间点草稿。
4. 点“去播控预览”，选择媒体正文方式。自动台词模式到时间点暂停并显示该组；手动模式使用“上一组 / 下一组”控制台词，时间点仍会让媒体暂停。每组台词默认按可用区域自动分页，使用“上一页/下一页”或左右方向键阅读，上下方向键切换台词组；换组回到第一页。翻组内页不会跳视频进度，也不会自动继续播放。读完点“读完继续”；拖动媒体进度条会暂停，确认位置后再播放。
5. 竖屏为上方媒体、下方台词；横屏可选择媒体在左或右。媒体模式切换横竖屏仍保留媒体，字幕方式、左右位置及其他排版分别使用该方向保存的设置。
6. 逐步应用只准备预览，点应用才把媒体、台词和位置一起上屏并暂停；实时同步按明确操作同步。预览默认静音，实时绑定时锁定静音，避免两边同时发声。观众浏览器若提示尚未允许播放，请在观众窗口点“播放”；声音是否能被直播客户端采集仍需实机核对。

“组内台词阅读”可改为连续滚动阅读。没有设置时间点时，每段正文作为一组；设置了时间点时，一组对应这个时间点关联的文字或插图。页码会随应用、实时同步和恢复一起保存；逐步应用时只在预览翻页，不改变观众画面。

自动台词使用人工选择的正文，不做语音识别或自动配字幕。没有媒体仍可正常滚动/分页；媒体打不开时可改回纯正文。删除被时间点引用的正文前，请先调整对应时间点。详细说明和样片状态见[音视频配本](音视频配本.md)。

## 保存与载入展示方案

“展示方案”包含一套系统默认设置和最多 10 套自定义方案，每套同时保存横屏、竖屏的字号、行距、留白、背景、列数、正文阅读方式、媒体台词模式、组内分页/滚动方式、横屏媒体位置和默认速度。

先调整需要的横屏和竖屏排版，再填写“自定义方案名称”并点“另存为新方案”。选择已有方案后可改名并“更新此方案”，或“删除方案”；更新和删除都需确认，删除不会改变当前画面。

| 操作 | 保存或改变什么 | 是否更新展示 |
|---|---|---|
| 保存当前画幅设置 | 只保存当前横屏或竖屏配置，供下次进入使用 | 此按钮本身不应用；实时模式下先前的排版操作可能已同步 |
| 另存为新方案 / 更新此方案 | 保存一套包含横竖排版的方案，不改当前保存配置 | 不更新 |
| 载入方案 | 把所选方案的两种画幅设置填入预览 | 逐步应用时等待应用；实时模式同步当前预览 |
| 应用到展示 / 立即同步 | 发布当前预览及其位置，并保存该画幅配置 | 更新 |

选择方案本身不会载入，仍需点“载入方案”。“系统默认设置”的横竖屏正文均优先使用分页，不删除其他自定义方案；已有方案明确保存的滚动或媒体方式仍保留。名称不能重复；达到10套后，可更新已有方案或先删除旧方案。

## 即时播控

即时播控现在位于预览底部，“暂停展示”始终显示，其余操作点“展示控制”展开。滚动模式的开始/速度/返回顶部/手动定位，分页模式的上一页/下一页及媒体播放操作，均直接控制当前已经上屏的内容，无需再次应用，也不会覆盖未应用预览草稿。媒体进度、时间点继续和台词切换可在媒体画面内操作。

- 自动滚动时会定期保存段落位置；暂停和手动定位时及时保存。
- 刷新播控页不会中断展示。
- 首次打开或刷新独立展示窗口，以及重新启动程序后，会恢复已上屏内容与最近保存的位置，并保持暂停；确认位置后再开始。滚动正文按段落恢复，分页正文按已保存页码恢复，媒体按最近保存的秒数、台词组及组内页码恢复。
- 意外关闭后按最近保存的位置恢复，不保证滚动正文回到完全相同的像素位置；更换字体或排版后分页会重新计算。

请通过“打开独立展示窗口”入口复用观众窗口，避免同时打开多个展示窗口争用当前位置。

## 管理分类和剧本

在“内容管理”中可以：

- 新增、编辑、搜索、隐藏和恢复分类，拖动或用上下箭头排序；选择主题色和背景素材。背景是分类属性，可以选用、更换或清除。
- 删除分类时，将其中的剧本转移到另一个分类或系统“未分类”。取消操作不改变数据，删除分类不会删除剧本。
- 新增或编辑剧本的名称、作者、简介、原配音备注、标签和待核事项；展开正文编辑逐段修改。
- 暂时隐藏剧本，再在管理页恢复。已应用的展示内容保持不变，直至重新应用。

原始分类、来源页码与原件独立保存。编辑后的资料写入本地数据库，原 PPT 保留作为证据。

## 手动添加正文图片

1. 打开“内容管理”，新增或编辑一个剧本，展开“编辑正文段落”。
2. 点底部“＋ 添加图片”将图片放到正文末尾；也可以在某段下方点“＋ 在此段后添加图片”，直接插入指定位置。
3. 选择本机 PNG、JPEG 或 WebP 图片，单张不超过 12 MB。上传完成后会出现缩略图，点击图片可查看大图。
4. 用“上移／下移”调整图片与文字的顺序；“替换图片”保留该段落的标识，“移除”从草稿中去掉该段。被音视频时间点引用的段落需先调整时间点才能删除。
5. 最后点击“保存剧本”。上传、替换、排序都先进入草稿，取消编辑不会改动原剧本；保存后也需重新应用才更新已上屏画面。

保存的图片可在阅读页、播控预览和展示页使用，并随完整资料备份保存。正文图片独立于分类背景，不会自动加入背景素材库。取消或移除的未保存图片不属于剧本，未引用的草稿图片不进入资料备份。原始 PPT 文件保持不变。

## 导入正文与复用角色

1. 在“内容管理”中新增或编辑剧本，展开“编辑正文段落”，点击“导入正文”。
2. 选择粘贴文本，或上传 TXT / DOCX 文件。TXT 不超过 2 MB，DOCX 不超过 10 MB；DOCX 读取段落和表格文字，本次不导入其中的图片。
3. 点击“识别并预览”，核对识别段落、原文对照、角色及提示。导入会自动跳过纯空行（含只有空格、制表符或全角空格的行），不把它们计作段落；原文对照保留这些空行，非空行内容不改。本地规则会尝试识别标题、作者和“角色：台词”格式，不调用在线 AI，也不会替用户改写正文。
4. 默认“追加到现有正文后”，保留所有原有段落、插图及来源。若明确选择替换，则替换文字段落，原插图连同 ID 和来源按原顺序保留在新文字末尾。
5. 点击“填入编辑器”仅更新当前草稿；标题和作者只在原字段为空时补充。继续修改后，点击“保存剧本”才写入资料库。尚未填入时，取消、识别失败或关闭识别窗口都不会改动草稿。

每个段落的“角色标签”可选已有角色，也可自由输入。默认配色优先采用“角色与默认颜色”中设置的颜色，未设置时沿用正文首个有效颜色。改变默认色不批量改旧句，需要时使用“统一该角色句子”，也可以保留单句特殊色和未修改的原多色片段。具体步骤见[编辑与导入](编辑与导入.md#给人物设定默认颜色)。

编辑窗口还提供本机自动草稿、恢复选择、撤销/重做及已保存版本恢复。“排版预览”采用未保存草稿，可检查横竖屏分页和滚动：点击正文、角色或颜色时，预览自动定位并标亮同一句；点击预览台词则返回对应编辑段落。输入过程中不抢走光标，重新分页后仍保留当前目标。

左侧编辑区独立滚动，右侧整页按窗口可用宽高适配；翻页栏和底部“取消 / 保存剧本”保持可见。“放大预览 / 恢复编辑”方便查看整页，窄屏改为上下布局。草稿不进入资料备份，正式保存与重新应用展示仍分别进行。图示见[编辑保护和预览说明](编辑与导入.md#边编辑边看实际排版)。

## 背景素材管理

在“内容管理 → 背景素材”上传 PNG、JPEG 或 WebP 图片（最多 12 MB），为素材命名、预览、重命名或删除。也可在分类编辑窗口直接上传，上传后自动选中；保存分类才会修改该分类的背景，取消编辑仍保留上传素材，供其他分类使用。

在分类编辑的“背景主题”中选择“通用素色（无背景图）”可清除当前分类背景。内置 PPT 背景保留原件；自定义图片若正被分类、正文、已上屏内容或历史记录引用，界面会说明引用并禁用删除。未引用的自定义图可以删除，移除分类背景不会擅自删除素材文件。

背景素材名称和图片（含暂未用于任何分类的素材）都随资料 ZIP 备份和恢复。图片会检查真实格式和尺寸，无法识别、截断或过大的文件不会进入素材库。

## 单篇剧本导入与导出

在“内容管理 → 剧本资料”中，每篇剧本旁的“导出”会下载一个单篇 ZIP。文件包含这篇已保存剧本的名称、作者、简介、标签、备注、正文、角色与颜色、插图，以及已有的关联音视频和暂停时间点。编辑窗口中的未保存草稿请先保存，再导出。

收到另一份单篇 ZIP 后，点击“导入单篇剧本”，选择文件并检查。无同名时选择分类并新增；与同名剧本内容相同则跳过，同名但内容不同默认跳过，可明确选择覆盖目标、核对差异并勾选确认。覆盖前保存旧版本，保留目标标识及本场关联，不修改已上屏快照；原本隐藏的剧本仍保持隐藏。多篇同名时系统不会代选目标。详见[查重与覆盖说明](编辑与导入.md#导入单篇剧本时检查重复)。

单篇包携带的是当前剧本内容，不包含全库设置、分类背景、旧修改记录或原始 PPT。分类名称供对照，分类主题采用接收方所选分类。整体迁移电脑仍使用下面的“备份与迁移”；完整备份 ZIP 和单篇剧本 ZIP 各有对应入口。

### 让其他 AI 帮忙整理正文

新增或编辑剧本，展开“编辑正文段落”，打开“导入正文”，即可找到“AI 整理提示词”。复制提示词，连同原文发给你使用的 AI；工作台本身不会发送正文到外部服务。

把 AI 返回的纯文本粘贴回来，点击“识别并预览”，核对角色与原文后“填入编辑器”，最后“保存剧本”。标题和作者写在开头；每次发言采用“角色名：台词”，一行一个发言，括号里的动作、语气也保留。纯空行会跳过。原文没有指定角色的内容保持独立段落，不自动猜测说话人。

标题、作者行也会保留在正文中；有需要可在编辑器中移除重复展示的行。AI 整理的文字仍需核对，图片、音视频通过工作台相应入口添加。

## 备份与迁移

在“内容管理 → 备份与恢复”下载完整 ZIP 备份。备份保存应用资料、分类、主题、队列、展示设置、自定义展示方案、正文、修改记录和图片素材，包括尚未选用的自定义背景，以及关联媒体、时间点、媒体状态和历史仍引用的旧媒体。单个音视频不超过 200 MB，备份解压总量不超过 512 MB；旧媒体历史也占用备份容量。

“完整恢复备份”会再次确认，并自动保存恢复前备份到 `instance/backups/`；它替换当前工作资料并暂停展示。若只想加入剧本，改用“仅合并剧本”，逐篇检查和选择新增、跳过或覆盖，保留分类主题、设置、本场和当前展示。详见[仅合并操作](编辑与导入.md#从完整备份仅合并剧本)。损坏或不匹配的文件不会直接当作数据库执行。

操作栏位置、操作反馈、同步目标及阅读偏好保存在当前应用会话中，桌面和普通浏览器分别保存，不包含在资料 ZIP 中。备份 ZIP 也不包含程序运行时或两个原始 PPT。换电脑时先复制完整项目文件夹，再按需恢复最新备份；请保留 `evidence/` 来源证据目录。迁移应在停止工作台后进行，避免复制正在写入的数据库。

## 本次范围与后续接入

当前使用抖音直播伴侣，通过窗口采集选择“喜娃微PIA · 独立展示”；浏览器模式则选择对应的 Edge／Chrome 展示窗口。工作台不直接开播或推流，实际视频、声音、画幅与窗口遮挡时的采集效果，仍需在直播伴侣预览中核对。

本地音视频配本已完成；AI 生成、转码/剪辑、ASR、自动对齐/烧录、跨设备和多人播控仍未实施。当前仍无需准备视频即可选本、阅读和展示。

## 常见情况

| 情况 | 处理方式 |
|---|---|
| 桌面工作台没有自动打开 | 先看启动窗口报错，确认整个 desktop/runtime/ 已解压；必要时用“浏览器模式.cmd”临时打开，勿混用两种模式 |
| 提示页面凭据失效 | 程序可能重启过，刷新当前操作页 |
| 内容已修改，但展示没变 | 重新核对播控预览，再点击“应用到展示”或“立即同步” |
| 找不到刚隐藏的分类或剧本 | 进入内容管理，清除筛选并恢复显示 |
| 展示没有自动滚动 | 分页模式使用上一页/下一页；滚动模式检查暂停或是否已到末尾 |
| 分页即时按钮暂时不可用 | 先打开独立展示窗口，等待页数计算完成 |
| 导入后在选本页找不到新剧本 | 确认已填入编辑器并点击“保存剧本”，再检查分类及显示状态 |
| 媒体选项不可用 | 先为当前剧本上传并关联有效文件，再回播控正文 |
| 观众窗口没有声音或提示未允许播放 | 在该窗口点播放/开声音，核对系统声音；实时预览保持静音属正常 |
| 时间点保存失败 | 每点至少选一块、时间不超时长且不重复；多段放同一点 |
| 提示已有实例，暂时打不开 | 等待启动完成；不要删除 instance/ 中的数据库 |

运行环境维护方法见[运行环境](运行环境.md)，来源问题见[来源内容核查](来源内容核查.md)。

## 桌面展示与同步档位

新版优先通过原“启动工作台.cmd”打开桌面工作台，展示窗口标题为“喜娃微PIA · 独立展示”；可在直播伴侣窗口采集中改选它。桌面与浏览器模式的即时通道不同，播控和展示请在同一个应用内操作。“浏览器模式.cmd”保留原入口。

交互预览新增目标30／60／90／120Hz，默认60；实际收发指标反映工作台消息频率，不代表直播伴侣采集FPS。媒体校准仍约10Hz，停止、翻页等操作即时生效。完整步骤与真实最小化采集验证边界见[独立展示器](独立展示器.md)。
