# 独立展示器（Windows 本地版）

更新：2026-09-18。沿用 Python + Flask + Jinja + SQLite 的本地服务，增加自带运行环境的桌面窗口。完整免安装交付包无需另装 Python、Node.js、OBS 或额外直播中转软件。

## 普通使用

1. 完整解压整个项目，双击 **启动工作台.cmd**。会打开“喜娃微PIA工作台 · 桌面版”；黑色服务窗口请保留，可以最小化。
2. 在桌面工作台中选本、预览，点“打开独立展示窗口”。观众窗口标题为 **喜娃微PIA · 独立展示**。
3. 在抖音直播伴侣的“窗口采集”里选择这个独立展示窗口。原来选中的 Edge/Chrome 窗口需要改选一次。
4. 先在未开播时检查伴侣预览。按原习惯逐步应用或实时同步；翻页、背景、图片和音视频配本仍使用原控件。
5. 用完双击 **停止工作台.cmd**，桌面窗口会在检测到服务停止后自动关闭。只关闭桌面窗口并不会停止 Python 服务；再次启动会复用服务，不重置正在展示的资料。

桌面版的播控和展示必须一起使用。不要把普通浏览器里的播控页与桌面展示窗口混用：即时位置和悬停消息属于不同应用会话，不会自动跨过去。原有资料和排版共用同一个本地数据库；操作反馈等本机偏好在两个界面中分别保存，桌面首次默认逐步应用。

若需要原来的方式，双击 **浏览器模式.cmd**。缺少桌面运行环境时，启动程序也会回退浏览器版。整个运行时应随项目复制；不要只复制 electron.exe。

## 已有旧版资料时

先从旧版“内容管理 → 备份与恢复”导出完整资料 ZIP；把新版解压到另一个文件夹，停止旧版后再启动新版并恢复该备份。不要用新版直接覆盖旧版 `instance/`，也不要同时运行两份工作台。恢复后核对剧本、图片、媒体和时间点；同步档位等本机偏好按需重新设置。详细步骤见[使用说明](使用说明.md#已有旧版本时怎样升级)。

## 同步档位怎么看

可在交互预览中选择目标 30／60／90／120 Hz，默认 60。它控制普通滚动和悬停位置消息的发送节奏。实际发送、接收频率受屏幕刷新率、机器负载和窗口状态影响，120 Hz 不代表抖音输出120帧。

逐步应用、未绑定、静止等状态会作相应说明。音视频时间校准维持独立的约10 Hz，翻页、暂停、拖进度等操作仍立即发送；没有把音视频反复定位提高到120次/秒。SQLite只存状态和检查点，不逐帧写库。

## 最小化同步与试用结果

桌面窗口使用 Electron，关闭该应用的后台动画与计时器节流，允许真实最小化；不会把“最小化”偷偷改为恢复或隐藏到角落。官方行为依据：[Electron WebPreferences](https://www.electronjs.org/docs/latest/api/structures/web-preferences)。

要区分三件事：收到最新指令、生成了新画面、直播伴侣采到了新画面。前两项可以由项目自动测试，最后一项还取决于直播伴侣采集方式、Windows和显卡。原生截图发生变化也不能代替直播伴侣验收。

**2026-09-18，用户试用后反馈“似乎已经解决”。** 目前记录为用户当前电脑上最小化同步初步恢复；换电脑或更改采集方式后，仍需按下面的方法检查。

当前桌面模式可按已试用方式使用。换电脑、切换采集配置或更换媒体后，开播前在伴侣预览中检查可见、被遮挡、最小化、恢复四种状态，并试一下滚动、翻页、视频暂停点和声音。若再次停帧，先恢复窗口并核对采集目标，必要时并排保持可见。

通过“浏览器模式.cmd”打开的 Edge／Chrome 展示仍有后台节流与绘制限制，建议保持未最小化；桌面试用反馈不适用于普通浏览器模式。

## 源码准备与维护

免安装目录已经准备好运行时，无需执行下面的命令。从 GitHub 只下载源码时，先准备 Python，再准备桌面组件：

```powershell
python tools/prepare_runtime.py
runtime\python.exe -X utf8 tools/prepare_desktop_runtime.py
```

桌面组件锁定 Electron 44.4.2 / Windows x64，来自官方发布资产。下载包与 SHA-256 见 `tools/desktop-runtime-lock.json`；约151 MB压缩包保留在 `vendor/`，解压到 `desktop/runtime/`，保留官方许可证。首次准备需联网，日常启动不联网下载组件。不使用系统 Node.js。

入口：`desktop/main.cjs` 与 `desktop/preload.cjs`。界面只加载传入的本机同源服务；渲染进程启用沙盒和上下文隔离，未开放任意文件、命令或脚本执行接口。只有受信顶层页面可以打开／恢复本应用展示窗口。桌面会话保存在所选资料目录的 `desktop-user-data/`，不加入备份 ZIP 或 Git。

启动诊断日志：`instance/desktop.log`。开发时 `run.py --no-browser --data-dir <独立目录> --port <测试端口>` 可只启动服务，桌面参数为 `--url=http://127.0.0.1:端口/ --data-dir=绝对目录`。`--diagnostics` 仅供开发验收，默认不开启帧订阅、截图或远程调试。

验收脚本：`tests/desktop_display.cjs`（隔离资料目录，真实窗口最小化）；结果见[实施与验收记录](实施与验收记录.md)。
