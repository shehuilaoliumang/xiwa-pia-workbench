# 独立运行环境

本项目使用项目目录内的 `runtime/python.exe`。启动不依赖 Codex、系统 PATH、在线字体或 CDN，也不修改系统 Python。

- Python 3.14.7，Windows x64 官方便携包，SHA-256 已按[官方发布页](https://www.python.org/downloads/release/python-3147/)校验。
- Flask 3.1.3、Jinja2 3.1.6、SQLite（随 Python）和 Waitress 3.0.2；完整依赖固定在 [requirements.txt](../requirements.txt)。
- [Waitress 官方说明](https://flask.palletsprojects.com/en/stable/deploying/waitress/)包含 Windows 支持。应用使用 Waitress，默认只监听 `127.0.0.1`。
- 分组背景图解码使用 [Pillow 12.3.0](https://pypi.org/project/pillow/12.3.0/)，Windows cp314 wheel 与 PyPI SHA-256 一致，包含 PNG/JPEG/WebP 支持；已随便携环境和离线包交付。
- 下载的 Python 包和全部依赖 wheel 保留在 `vendor/`，原始 URL 与校验值写入该目录的清单。许可证保留在运行时及各包的 dist-info 目录。

交付目录已经包含运行环境，日常使用直接双击[启动工作台.cmd](../启动工作台.cmd)。保留整个文件夹即可迁移；仅复制代码不包含用户数据库及运行时。

重建前请先停止工作台，并使用运行时目录以外的 Python，避免替换正在使用的程序。若从只含源代码的 Git 副本重建，可用系统 Python 执行 `python tools/prepare_runtime.py`。首次需要联网下载锁定的包；已有完整 `vendor/` 时可以离线重新解压。这个准备脚本只用于维护，不是日常操作要求。

`runtime/`、`vendor/` 和个人资料 `instance/` 不进入 Git。来源证据与需求截图仍由 `evidence/` 保存，归档原件保存在 `.local-archive/evidence-originals/`，运行环境准备不会改写它们。

## 应用运行与开发验收

正文分页、展示方案和TXT/DOCX识别随应用源码交付。DOCX提取使用Python标准库读取ZIP/XML，无需安装Word或调用云端服务；支持范围见[使用说明](使用说明.md)。

浏览器验收脚本需要Node.js、Playwright与本机Edge，这些仅用于开发验证，不是用户启动程序的依赖；交付运行时不承诺包含浏览器测试环境。测试目录、资料隔离和证据位置见[维护与文件索引](维护与文件索引.md)。

## 独立桌面展示组件

完整免安装交付包另带 Electron 44.4.2（Windows x64），校验记录见 `tools/desktop-runtime-lock.json`；运行时在 `desktop/runtime/`，官方安装包在 `vendor/`，均不进入 Git。日常用户无需另装 Python、Node.js 或 OBS；双击“启动工作台.cmd”默认进入桌面版，在直播软件窗口采集中选择“内容管理 · 展示窗口”。源码维护者在 Python 就绪后运行 `runtime\python.exe -X utf8 tools/prepare_desktop_runtime.py`。详情见[展示窗口](展示窗口.md)。
